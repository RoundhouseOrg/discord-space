# Roadmap

## v1 — the solo loop (target: 3–5 weeks solo)

- `/launch` with 4 starter hulls
- 20–40 system galaxy, `/jump` with travel time
- Jobs: mine, patrol, salvage, explore
- NPC combat encounters (patrol + low-sec jumps), button-driven
- NPC station market: buy/sell, drifting prices, sinks (fuel, repair)
- `/fit` with ~10 modules
- XP/levels unlocking 2nd-tier hulls
- Stats: `/ship`, `/log`, `/leaderboard`
- Rendered ship card
- Zero prefix commands; slash + autocomplete everywhere

Definition of done: a brand-new player in a 2-person server can go from
`/launch` to a second hull without ever needing a wiki.

## v1.1 — the server hook
- Ambient events triggered by server activity
- Server leaderboards
- `/compare`

## v2 — multiplayer
- PvP encounters (consensual duels first; piracy in low-sec later)
- Player-to-player trading (escrow, no direct transfers)
- Contracts / hauling missions posted by players
- Guilds / corporations

## Later / maybe
- Player-run market with order books
- Web dashboard (reuses `engine/`)
- Cosmetic shop
- Story arcs / seasonal events
